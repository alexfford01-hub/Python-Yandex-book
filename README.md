# Python-Yandex-book
###  Понимание различий в поведении пользователей из разных городов критически важно для развития сервиса «Яндекс Книги». В рамках этой задачи предстоит проанализировать активность москвичей и петербуржцев    
`Проект был реализован в Jupyter Notebook с использованием библиотек: pandas, scipy, matplotlib, seaborn, statsmodels для Z-теста, statsmodels для A/B-теста.`       
Цель проекта:   
Проверить гипотезу о том, что пользователи из Санкт-Петербурга проводят больше времени в приложении Яндекс.Книги по сравнению с пользователями из Москвы.

В рамках проекта предстоит:  
* Загрузить данные из файла yandex_knigi_data.csv.
* Проверить данные на дубликаты.
* Сравнить размеры и статистику групп из Москвы и Санкт-Петербурга.
* Провести проверку гипотезы с помощью t-теста.
* Определить уровень значимости и интерпретировать результаты.
* Подготовить аналитическую записку с описанием тестов и их интерпретацией.

### Вывод проекта:    
В первой части результат проверки гипотезы показал, что пользователи из Санкт-Петербурга проводят в среднем больше времени за чтением и прослушиванием книг в приложении, чем пользователи из Москвы.
- Для проверки выбран тест Манна — Уитни и уровень статистической значимости - 5%;
- Средняя активность пользователей в часах в двух группах (Москва и Санкт-Петербург) не различается. Гипотеза о том, что пользователи из Санкт-Петербурга дольше взаимодействует с контентом, чем пользователи из Москвы - отвергнута.;
- Вероятно, пользователи ведут себя схожим образом из-за того что находятся в крупнейших и экономически развитых городах России.

Во второй чати выяснели:
- В тесте участвовало более 3 761 человек в каждой группе;
- Новый интерфейс сработал: количество покупок заметно выросло.    
Ключевые цифры:  
- Рост конверсии — 2,2 процентных пункта;  
- Целевой показатель — 3 процентных пункта.
